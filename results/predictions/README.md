# Predictions

The per-timestep prediction CSVs (`{model}_{square}.csv`, 1008 rows each, actual vs predicted
Internet traffic for Dec 16-22) are generated by `src/final_evaluation.py` when you run the
9 model/square combinations. They are not included here since the raw per-timestep arrays
were never transferred outside the Colab session; only summary metrics were.

To regenerate: run the final evaluation loop (see README.md, Section 12), which writes these
files automatically to this folder.
